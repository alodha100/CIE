## 1. Create Commands

### 🎭 Role Prompt

> **You are a Program Manager launching a new Hybrid Work Policy.**

---

### 📝 Tasks

#### Business Proposal
Create a detailed business proposal for implementing a Hybrid Work Policy in a large enterprise. Include:
- Executive summary
- Benefits
- Risks
- Implementation plan

#### Mind Map
Create a hand-drawn mind map for Hybrid Work Strategy covering:
- People
- Technology
- Policies
- Risks
- Culture

#### Infographic
Create an infographic explaining benefits of hybrid work for:
- Employees
- Organisations

#### PowerPoint Presentation
Create a 6-slide PowerPoint presentation on Hybrid Work Policy for leadership review.

#### PDF-Style Document
Convert the hybrid work proposal into a polished, shareable PDF-style document for external stakeholders.

#### Policy Kit
Create a complete Hybrid Work Policy kit including:
- Employee email
- FAQ
- Onboarding guideline
- Manager checklist

- Find a free slot in Neeraj's calendar and create a meeting invite for next Monday to discuss **"Hybrid Work Policy Document"**
- Write an email to Neeraj regarding pending work on the hybrid work policy

## 5. Word

### Demo 1 — Draft from Prompt

**Open a blank Word document → use the Copilot draft prompt.**

> Write a project proposal for a cloud migration initiative. Make it formal and concise, suitable for executive review.

---

### Demo 2 — Rewrite & Tone Shift

Select a paragraph and try each of these:

```
"Make this more concise."
```

```
"Rewrite in a warmer, more welcoming tone."
```

```
"Make this suitable for a non-technical audience."
```

---

### Demo 3 — Summarise a Document

Open any long document (policy, annual report, SOP) and use the Copilot chat pane:

```
"Summarize this document in 5 bullet points."
```

```
"What are the key action items?"
```

```
"Who is the target audience?"
```

---

### Demo 4 — Draft from Reference Files

Use the `/` reference picker to pull content from files or emails.

**Examples:**

```
"Draft a meeting follow-up report using /[meeting transcript file] and /[project status doc]."
```

```
"Create a training summary using /[course outline] and /[feedback responses]."
```
